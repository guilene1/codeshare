# Final product review — 2026-10-07

The local production preview is available at http://localhost:8080 for review. No AWS deployment or GitHub push was performed.

1. **Changed:** Teaching-focused workspace terminology/copy, returning-instructor dashboard, descriptions/templates, safe live Markdown preview, persistent activity, explicit dashboard navigation and selected-code-to-block creation. Changes extend the existing implementation.
2. **Preserved:** Kodelumi branding, established editor layout, Monaco/Yjs/WebSockets, all 15 languages, independent snippets, secure student/editor links, backend authorization, permanent SQLite content, lazy lesson sessions, optional S3 backups and two-container Caddy/Node production architecture. No runtime dependencies or services were added.
3. **Landing:** Keeps the two-column hero and realistic editor preview with the requested headline/supporting copy. Capabilities replace free/no-signup marketing. Returning instructors see up to six recent courses and a link to all workspaces.
4. **My Workspaces:** Browser/device-specific private shortcuts. Search, recent/name sorting, descriptions, server counts, open/rename, student/editor link copying and local shortcut removal are available. Removal preserves server content; permanent deletion remains separately confirmed in settings. Metadata queries do not hydrate lesson content. Existing courses appear after opening their private editor link once.
5. **Workspace organization:** Existing nested folders, file tabs, supported teaching file types, creation/rename/deletion and folder/file ordering remain. The explorer is read-only for students. An explicit My Workspaces control saves a checkpoint before returning; cards restore lesson/file/view context.
6. **Code Blocks:** Existing instructor CRUD/language/order, optional titles, highlighted examples and compact commands remain. Each block copies only its exact content and gives temporary Copied feedback. Student management is unavailable.
7. **Selection workflow:** An instructor selects Monaco code and chooses Create Code Block from Selection in the context menu. Exact text and active language populate the dialog. Creating adds the block to the active lesson and opens Code Blocks. Students do not receive this action.
8. **Students:** Public links stay View Only. Students navigate, search, select/copy, read live Markdown, copy individual snippets and adjust personal theme/font settings. REST and Yjs mutations remain server-authorized; students do not inherit locally stored editor credentials.
9. **Persistence:** SQLite stores descriptions and meaningful structural/snippet activity alongside existing course content. No keystroke history or expiry deletion was added. Refresh, inactive-session reload, Node restart and Docker restart retain content. A real browser retained its shortcut across Docker restart and reopened the correct lesson with editor access.
10. **Verification:** TypeScript checks, frontend/backend production builds, nine backend tests, five browser acceptance tests, repeated product journeys and the enhanced Docker/Caddy/browser restart script passed. Dark/light dashboard, established landing/editor and mobile notes/copy screenshots were visually reviewed. See [ACCEPTANCE.md](ACCEPTANCE.md).
11. **Load:** One instructor plus 50 real read-only protocol clients passed a 256 KiB lesson / 100-update run, including ten reconnects, write rejection, cleanup and idle persistence. Local sampled Node peak RSS was 103.2 MiB; full fan-out P95 was 36 ms; sampled CPU peak was 63.2% of one core. See `load-test-report-product.json` and [LOAD_TEST.md](LOAD_TEST.md). These are local Docker measurements, not a Lightsail capacity guarantee.
12. **Limitations:** Shortcuts are tied to this browser; clearing storage removes private local access shortcuts but preserves server content. Markdown intentionally supports a small safe subset rather than full CommonMark/GFM extensions. File moves between folders and folder reparenting are not provided; nested creation and ordering are available. SQLite uses one Node replica. Public HTTPS, S3 upload/restore and sustained capacity on the actual Lightsail instance require later operator configuration and verification.

The final student-access update removes the public-link join/name flow entirely. Students open directly into View Only / Live; navigation, search, selection, Markdown and snippet copying remain available. Instructor management controls and dashboard navigation are hidden. Presence carries anonymous viewer counts instead of student names; private editor credentials and server-side write rejection remain unchanged.
